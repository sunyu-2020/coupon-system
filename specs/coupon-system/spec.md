# 需求说明

## 目标

开发一个优惠券发放与核销后端服务，支持优惠券模板创建、优惠券发放、优惠券核销三个核心能力，满足电商平台上商家和用户的优惠券管理需求。

## 范围

1. 商家可以创建优惠券模板，包含名称、类型、优惠值、门槛、有效期、发行量等属性
2. 用户可以领取指定模板的优惠券，系统需验证领取资格
3. 用户可以查询自己拥有的优惠券列表
4. 用户可以在下单时核销优惠券，系统需验证核销条件
5. 实现相关的业务规则验证，包括模板有效性、领取限制、核销条件等
6. 提供RESTful API接口，支持创建模板、领取、查询、核销等功能

## 非目标

1. 不实现前端界面，仅提供后端API服务
2. 不实现复杂的营销策略引擎
3. 不处理订单系统的集成（仅验证订单金额）
4. 不实现消息通知功能
5. 不实现优惠券的批量导入导出功能
6. 不处理高并发场景下的分布式锁机制

## 关键场景

1. 创建优惠券模板
2. 用户领取优惠券
3. 用户查询优惠券
4. 用户核销优惠券
5. 领取限制验证
6. 核销条件验证

## 假设

- 系统采用Java后端技术栈，使用Spring Boot框架
- 系统使用H2作为内存数据库，Mybatis作为ORM框架，Lombok简化代码，MapStruct处理对象转换
- 系统具备清晰的分层架构（Controller、Application、Domain、Infrastructure）
- 数据库使用关系型数据库存储优惠券相关信息
- 系统需要保证数据一致性，特别是优惠券数量限制
- 用户身份认证由其他模块处理，本系统只需验证用户ID
- 时间处理使用系统默认时区，或采用UTC时间
